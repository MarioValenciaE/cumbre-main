# Projects, clients, and tools

This area is the working index for Cumbre initiatives: prospective clients, active client work, internal tools, and reusable products.

## Confidentiality first

This repository may be public. Keep this area limited to public-safe summaries, decisions, reusable materials, and links to approved locations. Do **not** add client personal data, meeting transcripts, credentials, financial information, contracts, private exports, or proprietary source files here.

Keep confidential project material in an approved private workspace and link to it only when appropriate.

## Folder convention

Create one folder per organization, project, or internal tool. Use a clear, stable name:

```text
FOLDERS/
├── ProPES/
│   └── README.md
└── [future-project-or-client]/
    └── README.md
```

Each folder's `README.md` should contain only:

- Status: prospect, active, paused, completed, or internal.
- A one-sentence purpose.
- Confirmed scope and explicitly marked assumptions.
- Public-safe links to relevant repositories, tools, or documentation.
- Current next step and owner, if confirmed.
- Material decisions and dates.

Use the outline below when adding a new folder:

```md
# [Name]

- **Status:** [prospect / active / paused / completed / internal]
- **Last updated:** YYYY-MM-DD
- **Purpose:**

## Confirmed context

## Scope and deliverables

## Tools and repositories

## Decisions

## Next step

## Private material

State the approved private location only. Do not paste confidential content here.
```
