# Brand Guidance

Style: **minimalist, professional, modern, restrained.**

## Palette

| Name | Hex | Suggested use |
| --- | --- | --- |
| Ice White | `#F6F8F6` | Backgrounds |
| Charcoal | `#202724` | Body text, dark surfaces |
| Forest Green | `#153F35` | Primary brand color |
| Muted Green | `#356456` | Secondary accents |
| Granite Gray | `#68716D` | Secondary text |
| Sage Gray | `#DEE7E1` | Borders, subtle surfaces |

Suggested usage is a starting point, not a finalized brand system. Check text/background contrast for accessibility.

## Typography (suggested)

**Manrope** for headings, **Inter** for body text.

## Logo

The official logo is supplied separately. **Do not alter or recreate it.** Place approved files in [`assets/brand/`](../../assets/brand/README.md).

`cumbre-logo-provided.png` is a founder-supplied candidate used unchanged in the website MVP. Confirm its official status before a production launch.
